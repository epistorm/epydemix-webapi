## Overview
- Detailed documentation on populations, including overview, presets, and customizations
- Dependency updates

## Documentation

### Populations

The populations guide is now a category with three pages: **Overview**, **Population Presets**, and **Custom Populations**. The overview covers age-stratified simulations, contact-matrix heterogeneity, and how to calibrate `transmission_rate` from a target $R_0$.

### Running a Simulation

Added cross-links to the new Populations and Model pages, plus a `jq` one-liner for extracting the median peak of `Infected`.
